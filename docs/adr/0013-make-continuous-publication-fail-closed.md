# Make continuous publication fail closed

Every non-documentation push to `main` publishes a release, and manual publication is accepted only from `main`. `VERSION_NAME` is RenG's sole checked-in version input: a stable value above the public line requests an upward release, while a routine release selects exactly the next patch after the highest stable public version. Snapshot declarations are rejected before resolution. The resolver probes only its selected candidate and stops if that aggregate POM already exists; it never skips an occupied version. Public metadata, candidate probes, and every other remote read distinguish absence from failure, so malformed metadata, transport failure, and unexpected status codes stop the release rather than being treated as an empty repository.

A release builds, tests, signs, validates, and resolves from an isolated local repository before it can touch R2. The local publication supplies a manifest of its immutable versioned keys, and each exact key is checked against the authoritative bucket before upload. Any existing key proves that the version is complete, occupied, or partially uploaded, so publication stops without overwriting or deleting anything. Recovery from a partial release is a deliberate upward `VERSION_NAME` change, leaving a version gap rather than silently selecting another version or mutating public objects.

The publish job repeats the platform gates needed to stand on its own, including Linux x64 tests, rather than racing a separate CI workflow. After upload it fetches every versioned artifact anonymously, verifies that aggregate Maven metadata names the new release, and resolves the aggregate coordinate for all six targets with no credentials and a fresh Gradle home. Cycle A is complete only when this public path succeeds; a locally valid or merge-ready skeleton is not yet a published dependency.

This keeps continuous delivery without making an immutable Maven repository depend on optimistic HTTP behavior or atomic multi-artifact upload. Versions may have gaps, but a published coordinate is never replaced, partial state is never hidden, and remote uncertainty always stops rather than weakens the gate.
