KMP setup

RenG is configured for one public KMP coordinate. Installation becomes available only after both CI jobs pass the exact merged commit and the first public completion record verifies anonymously. The setup below is ready for that release.

Kotlin Multiplatform Six configured targets Apache-2.0 Release pending

The first public release is pending. Cycle A exposes no runtime API and renders nothing. This page describes the setup that becomes usable after anonymous first-release completion-record verification.

After that exact merged CI and public outcome, an authorized documentation-only follow-up must revise pending claims in CLAUDE.md, the README, overview, this setup, and llms.txt; adjust the versions.js fallback if applicable; and update the handoff plus decomposition while keeping versions metadata-driven. ADR 0013 and the Cycle A design spec and implementation plan remain historical decision records unless the release exposes a contract error.

Step 1

Add the repositories.

After anonymous first-release completion-record verification, RenG will resolve from the public Maven repository without consumer credentials. RenG's Rentile dependency also resolves Skiko platform artifacts from JetBrains' public Compose repository; limit that repository to its owner group.

settings.gradle.ktsroot project
dependencyResolutionManagement {
    repositories {
        maven("https://maven.rohittp.com")
        mavenCentral()
        google()
        maven("https://maven.pkg.jetbrains.space/public/p/compose/dev") {
            content { includeGroup("org.jetbrains.skiko") }
        }
    }
}

Step 2

Declare the common dependency.

Put the release value in a property. Keeping the declaration property-driven makes dependency updates explicit and keeps the documentation independent of the current public release.

gradle.properties
rengVersion=<version>
build.gradle.ktsshared module
val rengVersion = providers.gradleProperty("rengVersion")

kotlin {
    sourceSets {
        commonMain.dependencies {
            implementation("com.rohittp.reng:kmp:${rengVersion.get()}")
        }
    }
}
