KMP setup

RenG has one public KMP coordinate. Configure its repositories once, keep the release value in a Gradle property, and let Gradle select the matching target artifact.

Kotlin Multiplatform Six targets Apache-2.0 vlatest
Cycle A exposes no runtime API and renders nothing. This page documents publication setup only; it does not promise a callable rendering interface.

Step 1

Add the repositories.

RenG resolves from the public Maven repository with no consumer credentials. Keep it before the standard repositories. RenG's Rentile dependency also resolves Skiko platform artifacts from JetBrains' public Compose repository; limit that repository to its owner group.

settings.gradle.ktsroot project
dependencyResolutionManagement {
    repositories {
        maven("https://maven.rohittp.com")
        mavenCentral()
        google()
        maven("https://maven.pkg.jetbrains.space/public/p/compose/dev") {
            content { includeGroup("org.jetbrains.skiko") }
        }
    }
}

Step 2

Declare the common dependency.

Put the release value in a property. Keeping the declaration property-driven makes dependency updates explicit and keeps the documentation independent of the current public release.

gradle.properties
rengVersion=<version>
build.gradle.ktsshared module
val rengVersion = providers.gradleProperty("rengVersion")

kotlin {
    sourceSets {
        commonMain.dependencies {
            implementation("com.rohittp.reng:kmp:${rengVersion.get()}")
        }
    }
}
Published release: vlatest. This page reads Maven metadata after loading; if metadata is unavailable, the readable fallback remains latest.
